Git部署流程——一条命令，自动生效

GitHub推送 → Vercel自动部署；腾讯云服务器git pull → Cloudflare自动生效
# GitHub：Vercel自动部署的数据源
git remote add origin https://JuneZhu96:TOKEN@github.com/JuneZhu96/tuv-west-deploy.git
git push -u origin main

# 腾讯云服务器上（需SSH登录）：
cd /var/www/tuv-west-deploy && git pull origin main

每次更新：git add git commit git push origin main —— Vercel 10-30秒自动部署，腾讯云侧SSH登录后 git pull 拉取最新。Cloudflare Tunnel常驻运行，服务器文件更新后域名自动生效。

八戒点评：这套架构的精髓不是"选Vercel还是腾讯云"，是"两个都要，一个域名统管"。GitHub负责源码+自动部署，腾讯云负责国内稳定访问，Cloudflare Tunnel提供自有域名和HTTPS。为什么放弃Gitee？因为腾讯云+Nginx是自己可控的服务器，配合Cloudflare Tunnel可以绑定自有域名——junezhu.com.cn比gitee.io专业一百倍。

全流程实战——以本课程为例

真实项目：从HTML完成到全球可访问

Step 1：内容产出

Hermes Agent完成课程HTML——18章、TÜV品牌格式。放在 /d/tuv-west-deploy/ 目录。

Step 2：Git提交

git add && git commit && git push origin main

Step 3：Vercel自动部署

GitHub推送后10-30秒自动生效。URL：tuv-west-deploy.vercel.app/hermes-course.html

Step 4：腾讯云git pull

SSH登录服务器，cd /var/www/tuv-west-deploy && git pull

Step 5：Cloudflare Tunnel自动生效

Tunnel常驻运行，git pull后文件更新自动同步到 junezhu.com.cn/hermes-course.html

Step 6：微信发送

链接发微信——对方直接打开，无需附件，无需等待。域名是junezhu.com.cn，专业品牌感拉满。

踩坑记录： SSH密钥要先配好——腾讯云服务器需配置 authorized_keys 才能免密登录； Cloudflare Tunnel需在所有部署步骤完成后启动一次即可常驻。
